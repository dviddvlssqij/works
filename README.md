# works

Портфолио. Каждая работа — отдельная папка, один общий деплой.

| Папка | Что это | Тип |
|---|---|---|
| `kofe/` | Кофейня | концепт |

Концепт = сайт сделан по своей инициативе, без заказчика. В портфолио выглядит
так же, как клиентский: заказчика в работе не видно.

## Локально
```
python3 -m http.server 8000
```

## Деплой
GitHub → Cloudflare Pages. Build command пустой, output directory `/`.
